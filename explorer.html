Remote fetch (CORS)

Allen's download.alleninstitute.org does not send CORS headers, so direct browser fetch is blocked. Public CORS proxies work but are unreliable for many concurrent requests. Local folder is most reliable.

CCF to stereotaxic transform

CCFv3 is built from perfused brains and is not a stereotaxic targeting space. Relative to a flat skull (bregma & lambda at equal DV height, the Paxinos convention) it sits pitched ~5° nose-down and is scaled relative to it (most along DV, with smaller ML and AP differences). These controls correct the display so it looks like a flat-skull / Paxinos view. They do not change the underlying mesh data and are visualization aids, not a substitute for empirical stereotaxic calibration.
Scale is applied first (about bregma), then tilt.

Provenance

Default tilt & scaling follow Andy Peters' neuropixels_trajectory_explorer (the de-facto reference): bregma_ccf = [ML 570.5, AP 520, DV 44] vox, full scale = [0.952, -1.031, 0.885], ap_rotation = 5°. This viewer applies the 5° tilt and all three scale factors (ML 0.952, DV 0.885, AP 1.031). The reference lists AP as -1.031; the minus sign is only an axis-direction flip for the reference's CCF voxel ordering, so this viewer uses the magnitude 1.031 because its own AP axis already points anterior-positive. Scale is applied before tilt, about bregma. The 5° nose-down estimate is from Birman et al. (Pinpoint), bioRxiv 2022.05.09.491042. These are approximations; the CCF-vs-Paxinos tilt still carries known residual error, so tune the custom values against your own landmarks.
